# EPIC

This guide covers using EPIC (Explicit Planetary Isentropic Coordinate) as an atmospheric modeling application used to simulate planetary atmospheres and generate scientific output for analysis.

## Loading EPIC

```bash
$ module avail epic
$ module load epic
```

**Verify installation**:
```bash
$ epic --version
$ which epic
```
